# Phase Documentation

Every sub-phase gets one Markdown record after completion.

## File convention

```text
docs/phases/phase-XX/subphase-XX-YY-short-name.md
```

Each record contains:

- status and completion date;
- objective and delivered scope;
- files added or changed;
- decisions and deviations;
- verification commands and results;
- known limitations;
- restore/recovery procedure;
- remaining work and next sub-phase.

Use [the template](TEMPLATE.md) for future records.
